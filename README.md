# russiahomestead.org

Static RU/EN site of Russia Homestead: a practical route into rooted life in Russia for families, builders and specialists.

- `/` — Russian (primary language)
- `/en/` — English
- Related values framework and participation: https://russiacharter.org/ (RU) and https://russiacharter.org/en/ (EN)

No build step. Fonts are self-hosted in `/fonts/`. The application form posts to Formspree.
